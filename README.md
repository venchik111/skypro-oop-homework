# Ядро интернет-магазина

Учебный проект по ООП: товары и категории интернет-магазина.

Реализованы классы `Product` и `Category`, инициализация объектов и общие
счетчики категорий и товаров. Дополнительно реализована загрузка из JSON.
Добавлены приватные атрибуты списка товаров и цены, `add_product`,
геттеры `products` и `price`, сеттер цены и класс-метод `new_product`.
Используются классы, `__init__`, `classmethod`, `property`, циклы и списки.

## Структура

- `src/product.py` — товар: название, описание, цена и количество на складе.
- `src/category.py` — категория: название, описание и список объектов товаров.
- `src/utils.py` — функция `load_categories`, чтение JSON и создание объектов.
- `main.py` — пример добавления товаров, создания из словаря и изменения цены.
- `load_example.py` — отдельный пример загрузки JSON.
- `data/products.json` — исходные данные из задания без изменений.
- `tests/` — тесты pytest с фикстурами.
- `htmlcov/index.html`, `coverage.xml` — отчеты о покрытии.

`Category.category_count` увеличивается при создании категории.
`Category.product_count` увеличивается на длину переданного списка товаров,
а не на сумму остатков `quantity`. Счетчики общие для всех категорий
в текущем запуске Python. Повторная загрузка JSON создает новые объекты
и снова увеличивает счетчики. Метод `add_product(product)` также увеличивает
счетчик товаров на единицу. Список хранится в `__products`, а свойство
`products` возвращает строку с описанием товаров, по одному на строку.

Цена хранится в `__price` и доступна через свойство `price`. При попытке
установить нулевую или отрицательную цену выводится сообщение, цена сохраняется.
При снижении цены программа запрашивает подтверждение: `y` разрешает изменение,
любой другой ответ отменяет его. Повышение цены не требует ввода.

`Product.new_product(data)` создает товар из словаря. Необязательный аргумент
`products` позволяет передать список для поиска дубликатов по точному совпадению
названия. Новый объект получает суммарный остаток и максимальную цену.
Исходные объекты и список не изменяются; метод возвращает новый товар.

## Запуск в PyCharm

1. Выбрать **File → Open** и открыть папку проекта.
2. Выбрать интерпретатор проекта `.venv/bin/python`.
   На другом компьютере сначала выполнить `poetry install`.
3. Открыть `main.py`, нажать правой кнопкой и выбрать **Run 'main'**.
4. При снижении цены ввести `y` или `n` в консоли Run.
5. Для загрузки JSON запустить `load_example.py`.
6. Для тестов нажать правой кнопкой на папку `tests` и выбрать запуск pytest.

Python 3.11 или новее. Для основного кода сторонние библиотеки не нужны.
Зависимости для разработки зафиксированы в `poetry.lock`.

## Проверки в терминале

```bash
poetry install
poetry run python main.py
poetry run python load_example.py
poetry run pytest
poetry run flake8 src tests main.py load_example.py
poetry run black --check src tests main.py load_example.py
poetry run isort --check-only src tests main.py load_example.py
```

В `main.py` создается одна категория, затем в нее добавляется четвертый товар.
Тесты проверяют поля обоих классов, независимость товаров, общие счетчики,
пустую категорию, загрузку JSON, добавление товаров, создание из словаря
и изменение цены с подтверждением и отказом. Счетчики сбрасываются фикстурой перед
каждым тестом, чтобы результаты не зависели от порядка запуска.
Отчеты покрытия обновляются командой `poetry run pytest`.
